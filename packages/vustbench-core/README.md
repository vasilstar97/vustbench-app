# vustbench-core

Независимый Python-пакет расчёта обеспеченности. Не зависит от HTTP, React и
состояния веб-приложения; пригоден для последующего переноса в отдельный репозиторий.

```python
from pathlib import Path
from vustbench_core import load_catalog, load_city, load_services, run_baseline

manifest = run_baseline(
    data_dir=Path("data"),
    artifacts_dir=Path("artifacts"),
    service_name="school",
    mode="walk",
    progress=lambda stage, message: print(stage, message, flush=True),
)
```

`load_city()` возвращает `CityDataset` с `buildings`, `blocks`, `bounds4326` и
`metadata`. `load_catalog()` возвращает JSON-совместимый список нормативов с
признаками доступности исходного слоя и статистикой ёмкости. Неприменимые или
некорректные нормативы одного типа отражаются в его `available=False, error`.
`load_services()` возвращает GeoDataFrame с восстановленными ёмкостями и их
происхождением. Отсутствующий файл или некорректный выбранный тип вызывает ошибку.

## Методика MVP

- Население берётся из `population_balanced`; фильтр по `is_living` не применяется.
- Спрос задаётся каталогом на 1 000 жителей. Метод наибольших остатков сохраняет
  общегородскую сумму `ROUND_HALF_UP(население × норматив / 1000)`; равные остатки
  упорядочиваются по стабильным ID.
- Существующая `capacity` сохраняется. Только отсутствующие значения заменяются
  нижней медианой всех положительных целочисленных `units[].capacity`, включая
  повторения. Это конкретный каталоговый типоразмер: школа 300, детсад 180.
  Оценки отмечены `capacity_estimated`, `capacity_source`; исходное значение
  сохранено текстом в `capacity_original`. Площадь контура не определяет типоразмер.
- ID — `b:<номер исходной строки>` и `s:<тип>:<номер исходной строки>` в рамках
  версии набора данных. Совпадающие геометрии сохраняются как отдельные строки.
  Невалидные геометрии исправляются `make_valid` с сохранением ID; пустые и
  отсутствующие геометрии вызывают явную ошибку.
- Пока поддерживается `walk`. IduEdu загружает настоящий граф OSM; готовый
  `.urbangraph` можно передать через `graph_path` для воспроизводимого расчёта.
- Область загрузки — выпуклая оболочка коллекции кварталов с буфером в локальной
  UTM. Она не требует топологического объединения полигонов после проекции.
  Буфер `max(1000 м, 3T × 83.333 м/мин)`, для школ 3 750 м. Это область
  загрузки маршрутов, её нельзя считать административной границей города.
- `UrbanGraph.project_objects` добавляет проекции репрезентативных точек и
  пешеходные соединительные рёбра. IduEdu считает время в минутах с отсечкой 3T.
- ObjectNat 3.1.0 выполняет распределение при `seed=0`. Обеспеченность — доля
  спроса, удовлетворённая **в пределах T**. Назначения между T и 3T сохраняются
  отдельно; поэтому дефицит в пределах T отличается от неназначенного спроса.

## Артефакты и совместимость

Исходные графы кэшируются отдельно в `artifacts/graphs`. Завершённый расчёт в
`artifacts/runs/<id>` содержит манифест, здания, сервисы и кварталы в GeoParquet,
необязательные GeoJSON-экспорты (`export_geojson=False` для пакетной подготовки),
разреженную матрицу NPZ и отдельные ID её осей. Отсутствующий элемент NPZ означает
бесконечность; явно сохранённый ноль означает достижимый объект с нулевым временем.

Кварталы получают отношение сумм обеспеченного спроса и спроса зданий, а не
средний процент. Репрезентативная точка здания связывается с одним кварталом;
при совпадениях выбирается первый по исходному порядку. Эта привязка кэшируется
по версии зданий и кварталов. Здания вне кварталов остаются в общегородском
результате, но не добавляются в квартальные агрегаты.

ObjectNat 3.1.0 вызывает pandas `sparse.to_coo()` для таблиц с заполнителем
бесконечностью, который pandas не поддерживает. Локальный адаптер
[`native.py`](src/vustbench_core/native.py) предоставляет ожидаемые конечные пары
без уплотнения матрицы и без изменения установленных библиотек.

Тесты запускаются `python -m pytest packages/vustbench-core/tests -q` из корня
после установки пакета. Небольшой синтетический граф в тесте проходит настоящий
IduEdu → ObjectNat pipeline, включая нулевой маршрут, назначение вне T и отсечку
3T. Такой тест не является расчётом показателей Санкт-Петербурга.
